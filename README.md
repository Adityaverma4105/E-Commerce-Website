ABSTRACT
This project presents the design and development of an E-Commerce Website named Shoply. The platform allows users to browse products, filter them based on price, add items to a shopping cart, and maintain a wishlist. The system is built using modern frontend technologies and provides a user-friendly interface for seamless shopping experiences. The website demonstrates core e-commerce functionalities such as product listing, cart management, and wishlist handling. The data is managed locally, making it suitable for demonstration and learning purposes.

GRAPHICAL ABSTRACT
The system includes:
•	Homepage with featured products
•	Product listing page with filters
•	Shopping cart interface
•	Wishlist panel

CHAPTER 1:
INTRODUCTION

1.1 Identification of Client / Need / Relevant Issue
With the rapid growth of online shopping, there is a strong demand for simple and user-friendly e-commerce platforms. Small businesses need lightweight and affordable solutions to showcase and sell their products online. Shoply addresses this need by providing a basic yet functional shopping interface.

1.2 Identification of Problem
Many small-scale sellers lack access to customizable and simple e-commerce platforms. Existing platforms are often complex, costly, or require backend integration. There is a need for a simplified system demonstrating core shopping functionalities.

CHAPTER 2:
LITERATURE REVIEW

2.1 Timeline of the Problem
E-commerce systems have evolved significantly since the 1990s, with platforms like Amazon and eBay leading the market. Modern systems focus on usability and personalization.

2.2 Existing Solutions
•	Amazon – Large-scale platform 
•	Flipkart – Indian e-commerce platform 
•	Shopify – Website builder 

2.3 Bibliometric Analysis
Feature	Effectiveness	Drawback
Cart System	High	Requires backend
Wishlist	Medium	Needs storage
Filters	High	Complex logic

2.4 Review Summary
Existing systems are powerful but complex. A simplified version like Shoply helps in understanding core concepts.

2.5 Problem Definition
Develop a simple e-commerce website that:
•	Displays products 
•	Allows adding to cart 
•	Supports wishlist 
•	Filters products by price 

2.6 Goals/Objectives
•	Build a responsive UI 
•	Implement cart functionality 
•	Enable wishlist system 
•	Add filtering feature 
•	Ensure smooth navigation 





CHAPTER 3:
DESIGN FLOW / PROCESS

3.1 Evaluation & Selection of Features
Selected features:
•	Product listing 
•	Add to cart 
•	Wishlist 
•	Price filter 

3.2 Design Constraints
•	No backend (local storage only) 
•	Limited scalability 
•	Browser-based storage 

3.3 Analysis of Features
•	Cart: stores selected items 
•	Wishlist: saves favorite items 
•	Filter: adjusts product view 

3.4 Design Flow
Flow:
1.	User visits homepage 
2.	Clicks “Products” 
3.	Filters/searches products 
4.	Adds items to cart or wishlist 
5.	Views cart 

3.5 Design Selection
Chosen design is single-page application (SPA) for fast navigation and smooth UI.

3.6 Implementation Plan
•	Frontend: React.js 
•	Styling: CSS 
•	State management: useState
